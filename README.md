# Redux Toolkit Shopping Cart

React product and cart pages with Redux Toolkit cart state.

## Project structure

- `src/pages/Product.jsx`
- `src/pages/Cart.jsx`
- `src/redux/cartSlice.js`
- `src/redux/store.js`

## Getting started

Install Node.js and npm, then run:

```bash
git clone https://github.com/JAYANTI-THAKOR-941/redux-toolkit.git
cd redux-toolkit
npm install
npm run dev
```

Open the development URL displayed in the terminal.
